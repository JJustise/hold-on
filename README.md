# Hold On · V0.1

> 等一等，再决定。
> 一个安静、温柔的小森林，帮你觉察拿起手机之前的那一刻。

---

## 如何运行

这是纯静态网页，**不需要安装任何东西**，最推荐的方式：

1. 打开文件夹：`hold-on`
2. 双击其中的 **`index.html`**
3. 默认浏览器就会打开这个森林

如果双击没反应，也可以在「终端」里输入：

```bash
open "/Users/justise/Documents/Codex/2026-09-06/hi/outputs/hold-on/index.html"
```

> 小提示：所有数据只保存在你自己的浏览器里（localStorage），刷新页面不会丢。

## 怎么玩（一次完整的 Hold On 流程）

1. 打开网页，看到森林、大树、小溪、小女孩，以及草地上的一部手机。
2. 第一次打开时，手机旁有一行小字：**「如果你现在想玩手机，点一下它吧」**，点击手机。
3. 小白花（长在树根旁）会出现并和你说话：
   - 问你现在想不想玩手机 → 选择「是的」
   - 问你本来想用手机做什么 → 选择或自己写一个目的
   - 问你现在真的要开始玩了吗 → 选择「好，我要玩」
4. 小女孩会拿起手机，计时开始。**你可以离开电脑，去用你的真手机。**
5. 回来之后，重新打开这个网页（或切回这个标签页），小女孩会拿着手机等你，问你：
   - **「你现在想放下手机了吗？」** → 是的，我玩完了
6. 小白花会告诉你刚才用了多久，然后问你：
   - 原本想做的事情完成了吗？
   - 玩完之后心里是什么感觉？
7. 记录完成，小女孩放下手机，继续在森林里发呆、看花、玩水。

整个过程**没有批评、没有评分、没有自律打卡**，只是轻轻记下来。

## 环境会随时间变化

- **时间**：按北京时间（UTC+8）读取，一天会经历 清晨 → 上午 → 中午 → 下午 → 傍晚 → 夜晚。
  天空颜色、明暗、太阳/月亮/星星都会**平滑地**变化，不会突然切换。
- **季节**：按真实日期判断，但采用全年平滑曲线，不会“一到 9 月 1 日森林突然全黄”。
  例如 9 月刚入秋，画面仍然以绿色为主，只有一点点秋意；越往深秋，树冠越金黄。

> 想预览不同时间的森林，可以在网址后面加参数，例如：
> `index.html?t=18:35`（傍晚）、`index.html?t=22:00`（夜晚）、`index.html?d=2026-10-20&t=15:00`（深秋下午）

## 项目文件结构

```
hold-on/
├── index.html        # 森林场景 + 页面结构（所有画面都是 SVG 画的）
├── css/
│   └── style.css     # 柔和的样式、缓慢的动画、对话框外观
└── js/
    ├── util.js       # 小工具（颜色、时间换算、文字等）
    ├── time.js       # 北京时间 / 一天天色 / 季节曲线
    ├── data.js       # 本地保存（localStorage）：历史记录 + 进行中会话
    ├── story.js      # 与小白花的完整对话流程（状态机）
    └── main.js       # 把场景点亮：时间渲染、小女孩姿态、点击交互
```

为什么这样拆：方便以后加「日报/周报/数据分析」时，主要在 `data.js` 和新增页面里做，不用动场景。

## 数据存在哪里

浏览器本地存储，键名：

- `holdon.records.v1` —— 所有历史记录
- `holdon.session.v1` —— 正在进行中的“使用手机”会话（跨刷新恢复用）
- `holdon.flag.v1` —— 是否已完成过一次互动（控制首页提示）

清除浏览器站点数据即可全部清空。

## 小动物测试模式（开发用）

正常使用：小动物非常低频、安静地出现。

想快速检查小动物动画/位置时，在网址末尾加：

```
index.html?test
```

（`?animals` 也一样）此时小动物约每 3～9 秒出现一只，方便观察；去掉参数即恢复“安静、偶尔”的正常模式。
